Are AI coders more trouble than they’re worth?
<p>The majority of UK and US software development teams polled by independent research firm Coleman Parkes say <a href="https://www.techtarget.com/it-infrastructure/opinion/Software-development-in-2026-A-hands-on-look-at-AI-agents">artificial intelligence (AI) agents</a> struggle to find issues in complex code.&nbsp;</p> <p>The poll of 300 software developers and engineering leads, published in the <em>Overcoming the limitations of coding agents in complex software systems</em> report from Undo, found that 93% of software development teams have experienced AI hallucinations, leading to incorrect diagnosis of problems in code. Over half (55%) say agents introduce incorrect code too frequently, creating rework that delays delivery cycles. In fact, 94% admit they are losing productivity due to having to analyse AI-generated code at least once a month.</p> <p>Undo, which provides tools for debugging code, found that developers tend to spend twice as <a href="https://www.computerweekly.com/news/366629372/AI-advances-clear-path-to-software-development-careers">long debugging code as they do writing it</a>, averaging 16.9 hours a week because software engineers are unable to keep up with the coding agents they use. The poll found that more than a third (35%) of AI-generated code reaches production before software development teams fully understand what the code actually does.</p> <p>This leads to coding errors being introduced in production systems.&nbsp;</p> <p>While AI coding agents can potentially dramatically reduce the cost of creating code, the poll from Undo suggests that bottlenecks have been pushed downstream, which means engineers are now struggling to understand the code being produced, leading to them having to spend more time on debugging and incident investigations.</p> <p>According to Undo, if the promised productivity gains of using AI coding are to be realised, AI must be applied to the software delivery cycle, not just code generation.</p> <p>Undo warned that the difficulty of understanding why an application behaves the way it does, coupled with AI’s tendency to give confident answers from incomplete evidence, makes it <a href="https://www.computerweekly.com/news/366643521/Handling-AI-disruption-and-failure-to-deliver">prone to hallucinate</a> the cause of bugs and instabilities.
